# 🎬 Netflix Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing the Netflix Titles Dataset using Python and popular data analysis libraries. The objective was to clean the dataset, perform exploratory data analysis (EDA), create meaningful visualizations, and derive business insights from the data.

## 📊 Project Workflow

### Step 1: Data Loading & Inspection
- Loaded the Netflix dataset
- Examined shape, columns, and data types
- Identified missing values and duplicates

### Step 2: Data Cleaning
- Handled missing values
- Removed unnecessary columns
- Fixed data inconsistencies
- Ensured data integrity

### Step 3: Exploratory Data Analysis (EDA)
- Movies vs TV Shows count
- Top countries producing Netflix content
- Titles released after 2020
- Rating category analysis
- Statistical analysis of release years

### Step 4: Visualizations
Created 8 visualizations including:

1. Bar Chart
2. Line Chart
3. Histogram
4. Scatter Plot
5. Pie Chart
6. Heatmap
7. Box Plot
8. Bubble Plot

### Step 5: Insights Report
Generated business and research insights based on the analysis and visualizations.

---

## 📈 Key Findings

- Movies account for nearly 70% of Netflix content.
- The United States contributes the highest number of titles.
- Netflix content production increased rapidly after 2010.
- Most titles were released between 2013 and 2019.
- Release year and movie duration show a weak negative correlation.
